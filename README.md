# PEIA Academy | أكاديمية هندسة المشاريع والابتكار

**Project Engineering & Innovation Academy**

أكاديمية عربية مفتوحة لتعلّم علم وهندسة المشاريع والابتكار، تجمع التفكير العلمي بالهندسة العملية وريادة الأعمال.

## الموقع

- الموقع المنشور: https://peia-academy.vercel.app/
- هذا المستودع هو مصدر الحقيقة الرسمي للمشروع.

## البنية

```
website/          # الموقع الثابت (HTML/CSS)
docs/             # وثائق الأكاديمية
curriculum/       # مخطط الوحدات
lessons/          # محتوى المحاضرات
youtube/          # خطة القناة والمحتوى المرئي
.github/workflows # CI
```

## الوحدات الاثنتا عشرة (مخطط)

1. علم اكتشاف الفرص والابتكار
2. التحقق من الأفكار ودراسة الجدوى
3. هندسة المنتجات وتجربة المستخدم
4. هندسة البرمجيات والمعمارية
5. التطوير والتنفيذ
6. الجودة والموثوقية
7. الأمن السيبراني وهندسة الثقة
8. الذكاء الاصطناعي التطبيقي
9. البنية التحتية والتقنيات الحديثة
10. إدارة المشاريع والفرق
11. ريادة الأعمال والتسويق والنمو
12. مشروع تطبيقي متكامل

## ملاحظة هامة

PEIA برنامج تعليمي مفتوح **غير معتمد** أكاديمياً أو مهنياً. تُوثق مصادر المحاضرات وتُراجع عند تحديثها.

المشروع مستقل تماماً عن أي منصة تجارية أخرى.
