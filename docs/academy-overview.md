# نظرة عامة على أكاديمية PEIA

أكاديمية هندسة المشاريع والابتكار (PEIA) برنامج تعليمي مفتوح عربي أولاً، يهدف إلى بناء معرفة علمية وهندسية متكاملة في:

- اكتشاف الفرص والابتكار
- هندسة المشاريع والمنتجات
- البرمجيات والمعمارية
- الجودة والأمن السيبراني
- الذكاء الاصطناعي التطبيقي
- البنية التحتية
- ريادة الأعمال

المشروع مستقل تماماً ولا يرتبط بأي منصة تجارية أخرى.

الموقع الحالي: https://peia-academy.vercel.app/
